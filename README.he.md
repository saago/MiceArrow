# Mice Arrow

[English](README.md) | [עברית](README.he.md)

Mice Arrow היא תוכנה ל־Windows ליצירה ולניהול של פרופילי סמן ולהחלת סמנים מותאמים אישית במערכת. אפשר לעצב סמן מתמונת PNG או ICO, לשנות את הגודל והצבע, להוסיף הילה, לקבוע את נקודת הלחיצה ולעבור בין פרופילים ידנית או לפי היישום הפעיל.

התוכנה משנה את הגדרות הסמן של Windows; היא אינה מזריקה DLL, מתקינה Hooks או מציירת שכבת־על במשחקים. יישומים ומשחקים שמציירים סמן בעצמם עשויים להתעלם מסמן Windows.

נוצר על ידי **נתנאל אלחדד** · [Nati3210@gmail.com](mailto:Nati3210@gmail.com)

## תכונות

- יצירה ושמירה של פרופילי סמן מתמונות PNG/ICO אישיות או מתוך אוסף הסמנים המובנים בתיקיית `Pointers`.
- התאמת גודל הסמן (1%–800%), צבע, שמירת צבעי המקור, נקודת לחיצה והילה אופציונלית.
- תצוגה מקדימה חיה ביחס 1:1, בלי להחיל את השינויים על Windows.
- החלת הסמן על מצבי החץ הרגיל והעבודה ברקע של Windows. במצב עבודה ברקע הסמן המותאם מופיע לצד טבעת מונפשת.
- קיצור מקשים גלובלי למעבר בין פרופילים, שיוך פרופילים ליישומים ומזעור למגש המערכת.
- שחזור הגדרות הסמנים של Windows שנשמרו לפני ההחלה הראשונה.

הסמן, כולל ההילה, חייב להיכנס למידות 256 × 256 פיקסלים. אפשר לקבוע את נקודת הלחיצה בלחיצה על התצוגה המקדימה; זיהוי השפיץ האוטומטי מתעלם משוליים שקופים.

## הפעלה ב־Windows

אפשר להוריד קובץ הפעלה עצמאי מעמוד GitHub Releases של הפרויקט, אם פורסם בו. לחלופין, אפשר לבנות אותו מקוד המקור לפי ההוראות בהמשך.

להפעלה מקוד המקור, התקינו Python 3.10 ומעלה והפעילו PowerShell בתיקיית הפרויקט:

```powershell
python -m pip install -r requirements.txt
python mice_arrow.py
```

## שימוש בסיסי

1. בחרו **פרופיל חדש** והזינו שם.
2. בחרו קובץ PNG/ICO, או בחרו תמונה דרך **סמנים מוכנים**.
3. התאימו את הגודל, הצבע וההילה. סמנו **שמור על הצבעים המקוריים** כדי לשמר את צבעי התמונה.
4. לחצו על הסמן בתצוגה המקדימה כדי לקבוע את נקודת הלחיצה, או השתמשו בזיהוי האוטומטי של השפיץ.
5. שמרו את הפרופיל. לחצו על **החלת הסמן במערכת** כדי להחיל את העיצוב הנוכחי. בהחלה הראשונה תוצג בקשת אישור והגדרות הסמן הקודמות של Windows יישמרו.
6. לחצו על **שחזור הסמנים המקוריים** בכל עת כדי לשחזר את ההגדרות שנשמרו.

בחירת פרופיל שמור מחילה אותו אוטומטית. הפרופיל נשאר מוחל גם לאחר סגירת התוכנה והפעלה מחדש של Windows. לאחר כניסה מחדש ל־Windows או טעינה מחדש של ערכת הסמנים, Windows עשוי לשנות את גודל הסמנים; במקרה כזה יש להחיל את הפרופיל שוב. בדרך כלל אין צורך בהרשאות מנהל.

קיצורי מקשים: `Ctrl+S` שומר את הפרופיל הנוכחי ו־`Ctrl+N` יוצר פרופיל חדש.

## אוטומציה ומגש המערכת

פתחו את **אוטומציה והגדרות** כדי להגדיר:

- **קיצור גלובלי למעבר בין פרופילים:** ברירת המחדל היא `Ctrl+Alt+F8`; אפשר לבחור גם `Ctrl+Shift+F8`,‏ `Ctrl+Alt+Right` או ללא קיצור.
- **פרופיל לכל יישום:** שייכו פרופיל שמור לנתיב המלא של קובץ `.exe` של יישום. יש להחיל פרופיל ידני פעם אחת לפני הפעלת ההחלפה האוטומטית. יישומים ללא שיוך משתמשים בפרופיל הידני האחרון.
- **מגש המערכת:** מזערו את החלון למגש ולחצו לחיצה כפולה על הסמל כדי לפתוח אותו מחדש. בתפריט המגש ניתן לעבור לפרופיל הבא, להשהות את האוטומציה, לשחזר סמנים או לצאת. כברירת מחדל, סגירת החלון יוצאת מהתוכנה; אפשר להגדיר שהיא תמזער למגש במקום זאת.

האוטומציה וקיצורי המקשים פעילים רק כשהתוכנה פתוחה, גם כשהיא ממוזערת למגש. יציאה מהתוכנה אינה משחזרת את הסמנים אוטומטית. הפעלה אוטומטית עם Windows אינה כלולה.

## בנייה מקוד המקור

```powershell
python -m pip install -r requirements-build.txt
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\build.ps1
```

הקובץ העצמאי ייווצר ב־`dist\MiceArrow.exe`. אוסף הסמנים המובנה `Pointers` נארז בתוך קובץ ההפעלה; אין צורך ב־Python במחשב שבו מפעילים אותו.

## נתונים ובדיקות

נתוני המשתמש נשמרים בתיקייה `%APPDATA%\MiceArrow`:

- `profiles.json` — פרופילי הסמנים השמורים
- `settings.json` — הגדרות האוטומציה, שיוכי היישומים והפרופיל הידני האחרון
- `active.cur`,‏ `working.ani` ו־`cursor_backup.json` — סמנים שהוחלו וגיבוי הסמנים המקורי

להפעלת הבדיקות מתיקיית הפרויקט:

```powershell
python -m unittest discover -s tests
```
